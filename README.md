# たまにPDF

> たまに使うPDFツール

仕事やプライベートで **たまにPDFを操作したいだけ** の人のための、ブラウザ完結型のPDFツールです。
インストール不要・アカウント不要・**アップロード不要**。スマートフォンでもPCでも使えます。

**→ https://masakiniwa.github.io/TaMaNi-PDF/**

## ファイルはあなたの端末から出ません

このツールには、ファイルを受け取るサーバーが存在しません。
PDFの読み込み・編集・書き出しはすべてブラウザの中で行われます。

これは方針としてだけでなく、**技術的に外部送信の経路がない状態**として担保しています。

| 担保方法 | 内容 |
| --- | --- |
| サーバ処理なし | バックエンドを持たない静的サイト。処理は `pdf.js` / `pdf-lib` によるクライアント処理のみ |
| CSP `connect-src 'self'` | 外部への `fetch` / `XHR` / `WebSocket` をブラウザレベルで禁止 |
| 依存アセットの自己ホスト | フォント・アイコン・CMap・wasm を含め CDN を一切使わない (外部ドメインへの接続が0件) |
| 解析ツールなし | アクセス解析・エラー収集・広告タグを入れていない |
| 保存先はローカルのみ | 設定と墨消しテンプレート (範囲の座標) は `localStorage`。PDFそのものは保存しない。自動位置合わせを**オンにしたときだけ**、96px幅の白黒簡易画像がテンプレートに加わる (既定はオフ) |

「外部ドメインへの通信が0件であること」は
[通しテスト](scripts/smoke-test.mjs) で毎回検証しています。

## できること

### ページ整理

- ページの並べ替え (各カードのつまみをなぞるだけ / タッチ操作対応)
- ページの回転 (90°単位、ページごと・全体)
- ページの削除・複製、**選択したページだけを残す** (いらないページを1枚ずつ消さなくてよい)
- ページの追加 (別のPDF / JPEG・PNG画像 / 空白ページ)
- **追加するページを選べます** — あとからPDFを足すとき、中身を見て必要なページだけ入れられます
  (設定で「すべて追加する」にも切り替えられます)
- PDFがなくても、**画像から新しいPDFを作り始められます**
- **画像の取り込みが速く、PDFも小さくなります** — 画像はブラウザで読める大きさのJPEGに刷り直してから
  埋め込みます (A4相当のスキャン画像10枚・計51MBで、取り込み16.5秒→1.9秒 / 出力35.7MB→8.4MB)。
  画質は設定で「ほどほど (既定) / 小さめ / 元のまま」から選べます
- 元に戻す・やり直す
- 書き出しは一覧の上のツールバーに常駐 (ページ数が多くても下までたどらなくてよい)
- **ページ番号の付与** (位置6か所 / 書き方4種 / 開始番号 / 文字の大きさ / 1ページ目を飛ばす)。
  元のページには触れないので文字は文字のまま残ります
- **ページ数が多くても軽い** — 数百ページでも、一覧は画面に入る行だけを描きます
- **ページを全画面で確認** — サムネイルを押すと1ページだけ大きく表示します。
  2本指のピンチ・ダブルタップで拡大でき、そのまま回転・削除・選択もできます
- **サムネイルの大きさをその場で変更** (小 / 中 / 大 / 特大)。スマホでは「大」以上で1列になり、実際に大きく表示されます
- 出力は元のページ内容をそのままコピーするので、**文字は文字のまま残ります**

### 墨消し

隠したい範囲をドラッグで囲んで塗りつぶします。

**黒い四角を重ねるだけの墨消しは、下にある文字がそのまま残ります。**
コピー&ペーストや別のソフトで開くと読めてしまう、よくある事故です。

たまにPDF は全ページを一度 **画像に変換してから** 塗りつぶし、その画像だけで
PDFを作り直します。隠した部分の情報は出力されたPDFの中に残りません。

- 塗りつぶし色は黒 / 白
- 適用先は「このページのみ / 全ページ / 奇数ページ / 偶数ページ / 最終ページ」から選択
- 作った範囲は**タップで選択 → ドラッグで移動、右下のつまみで大きさ変更**
- **2本指のピンチで拡大・縮小、2本指のドラッグで上下左右に移動** (100〜400%)。
  パソコンではホイールで移動、Ctrl+ホイールで拡大縮小。拡大時はページを描き直すのでぼやけません
- 取り消し / やり直しに対応
- **PC・タブレットの横長の画面ではPDFが高さいっぱいに広がり、操作パネルが右に並びます** (ツールバー・説明・範囲一覧を横のスペースに寄せた1画面レイアウト)。
  スマホは向きを変えても縦長と同じ並びのままです
- ページ数とページサイズは維持されます
- 画像化するため、出力PDFは文字検索・テキスト選択ができなくなります (ヘルプにも明記)

### サイズ圧縮

「PDFが大きすぎて、システムの上限に引っかかって出せない」ときのための機能です。
写真やスキャンでできたPDFを、読める品質のまま軽くします。

- **収めたい大きさ (1 / 2 / 3 / 5 / 10MB) を選ぶだけ** — 届くまで画質を一段ずつ落として自動で試します
- 画質を自分で決めたいときは、4段 (きれいめ 200dpi / 標準 150dpi / 小さめ 110dpi / とにかく小さく 80dpi) から選べます
- **元と圧縮後を並べて見比べられます** (押すと全画面)。粗くなりすぎていないか確かめてから保存できます
- **小さくならなかったときは、そう表示します** (「圧縮しました」とは言いません)。
  文字中心のPDFはもともと小さいため、画像化するとかえって大きくなることがあります
- 文字の多いPDFには、読み込んだ時点で注意を出します
- 墨消しと同じ仕組み (全ページを画像として刷り直す) なので、文字検索・テキスト選択は失われます

### 墨消しテンプレートと一括墨消し

同じ発行元・同じ書式のPDF (請求書や明細など) を繰り返し墨消しするための機能です。

- 指定した範囲をテンプレートとして保存・呼び出し
- **自動位置合わせ (既定はオフ)** — 同じ書式でも中身がずれているPDFに、範囲を合わせてから適用します。
  テンプレート保存時のページと適用先のページを見比べて、平行移動 (±12%) と拡大縮小 (±5%) を推定します。
  補正量と一致度はプレビューと一覧に表示され、似た配置が見つからないときは補正しません。
  オンにすると、テンプレートに **96px幅の白黒簡易画像** が保存されます
  (本文が読める大きさではありませんが、大きな見出しなど内容の一部が判別できる場合があります)。
  ずれを測るのは基準にした1ページだけで、その結果を全ページに当てます
- 複数のPDFにテンプレートをまとめて適用 (一括墨消し)
- 実行前に**代表1件でプレビュー**して、テンプレートがどこに当たるか確認できます
- 出力は個別ダウンロード、または ZIP でまとめて保存
- テンプレートは JSON で書き出し / 読み込みが可能 (端末間の持ち運び用)
- 自動位置合わせは設定で切り替えます。オフのあいだは簡易画像を保存せず、座標だけのテンプレートになります

範囲はページに対する **割合 (0〜1の正規化座標)** で保存しているため、
用紙サイズが違っても同じ位置に当たります。

### 作業を失わないための作り

- **画面を移っても作業は消えません** — ヘルプや設定を見に行っても、読み込んだPDFと編集内容はそのまま残ります
- 範囲を指定したまま別のPDFへ切り替えるときは確認します
- 読み込んだPDFがあるあいだにタブを閉じようとすると、ブラウザの確認が出ます
- テンプレートを端末に保存できなかったときは、その旨をはっきり伝えます (「保存しました」とは出しません)

### 一括墨消しの安全策

- テンプレートや画質を変えると、前の条件で作った結果は破棄して作り直しを促します
  (別のテンプレートで作ったPDFがZIPに混ざらないようにするため)
- **当たる範囲が1つもないPDFは失敗として止めます** (何も隠れていないPDFを完了扱いにしない)
- 一部の指定が当たらないときは、その指定を結果に表示します
- 終了時は「完了○件 / 失敗○件」を表示します

### その他

- 設定 (テーマ / サムネイルの大きさ / 画像の取り込み画質 / 解像度 / 画像形式 / 既定の塗りつぶし色 /
  ファイル名の接尾辞 / 自動位置合わせ)
- ヘルプ (使い方・墨消しの仕組み・プライバシー・FAQ)。長い説明は見出しごとに折りたためます
- バージョン情報とリポジトリへのリンク

## 技術構成

| 項目 | 採用 |
| --- | --- |
| ビルド | Vite + TypeScript |
| UI | React 19 + 自前の Material Design 3 CSSトークン |
| PDF描画 | [pdf.js](https://github.com/mozilla/pdf.js) (`pdfjs-dist`) |
| PDF生成・編集 | [pdf-lib](https://github.com/Hopding/pdf-lib) |
| 並べ替え | [dnd-kit](https://github.com/clauderic/dnd-kit) |
| ZIP | [fflate](https://github.com/101arrowz/fflate) |

アイコンはすべてインラインSVG、フォントは端末のシステムフォント。
外部リクエストを0件に保つため、UIライブラリや Web フォントの CDN は使っていません。

## 開発

```bash
npm install
npm run dev        # 開発サーバ
npm run build      # 本番ビルド (dist/)
npm run typecheck  # 型チェック
npm run test:e2e   # ビルドして実ブラウザで通しテスト
```

`npm run test:e2e` は Playwright + Chromium で以下を検証します。

- 各画面が表示できること
- **説明の折りたたみ** (最初は見出しだけが並び、押すと中身が開く・もう一度押すと閉じる)
- **作業内容が消えないこと** (ヘルプ・設定を見て戻ってもページと範囲が残る・
  隠れている画面のボタンがアプリバーに出ない・別PDFへの切り替え確認)
- **一括処理の結果管理** (当たる範囲がないPDFを止める・テンプレートを変えると前の結果を残さない)
- **ダイアログ** (入力しても焦点が入力欄に残る)
- **トリミング済みPDF** (ページ番号が表示範囲に入る)
- **壊れたテンプレートJSON** (読み込まずに知らせる)
- ページ整理: 読み込み・削除・回転・並べ替え・Undo/Redo・書き出し (回転が出力に反映されるか)
- **一覧の大きさ変更と「選択以外を削除」** (ツールバーで大きさが変わり設定にも残るか・
  選んだページだけが残るか・元に戻せるか)
- **ページの拡大表示** (大きく描き直すか・**ページ全体が枠に収まるか**・ページ送り・拡大・
  スマホでのピンチ・開いた直後の操作対象)
- **追加するページの選択** (最初の読み込みは全ページ・2件目からは選べる・設定で無効化・
  **複数ファイルで前の選択が残らないこと**)
- **当たらない範囲の検出** (単体の墨消しでも書き出しを止めること)
- **全ページ削除しても「戻す」が残ること**
- **ページ番号** (指定した位置に実際に描かれるか・入れないときは描かれないか・
  1ページ目を飛ばせるか・元の文字が文字のまま残るか)
- **150ページのPDF** (一覧が間引かれること・下まで送ると最後のページが出ること・
  間引いても全ページが書き出されること)
- 墨消し: 隠した文字が出力PDFから消えていること、塗った範囲が実際に黒くなっていること、
  範囲の移動・サイズ変更・拡大表示・クリア
- テンプレートの保存と一括墨消し、ZIP出力
- **自動位置合わせ** (既定がオフであること・オンにすると基準画像つきで保存されること・
  中身をずらしたPDFで塗る位置が実際にずれに追従すること・オフだと補正しないこと・
  ヘルプの説明がオンとオフで切り替わること)
- **スマホのタッチ操作** (つまみをなぞると並べ替えられること、つまみ以外をなぞったときは
  並べ替えではなくスクロールになること、指での範囲指定と移動、2本指のピンチ拡大)
- 一括墨消しの適用前プレビュー
- **表示がちらつかないこと** (ピンチ中に表示領域の大きさが揺れない・描き直しが繰り返されない・
  拡大後も絵の縦横比が保たれる)
- **横長の画面** (PCではPDFの横に操作パネルが並び、ページ全体が縦スクロールなしで収まること・
  横向きのスマホでは縦長と同じ並びのままで、下のナビゲーションが残ること)
- **画像の取り込み** (画質の設定でPDFの大きさが実際に変わること)
- **サイズ圧縮** (スマホの拡大表示で紙全体が見えること・画像PDFが実際に小さくなること・ページ数が変わらないこと・
  小さくならないPDFではそう伝えること・圧縮後に文字データが残らないこと)
- **外部ドメインへの通信が0件であること / CSP違反が0件であること**

Chromium の場所を指定したい場合は `CHROMIUM_PATH` を設定してください。

## 既知の制限

- パスワード保護されたPDFは扱えません
- 墨消しとサイズ圧縮の出力は画像PDFになるため、文字検索・テキスト選択・しおり・注釈は失われます
- すでに圧縮された画像PDFや、文字中心のPDFは、サイズ圧縮しても小さくならないことがあります
- ページ数が多いPDFや高解像度の指定は、端末のメモリを多く使います
